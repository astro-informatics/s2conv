Utilities
=========

Index conventions, Wigner functions and rotations, evaluation at arbitrary points, and
equivariance errors.  The modules are as follows.

.. list-table::
   :header-rows: 1
   :widths: 35 65

   * - Module
     - Contents
   * - :mod:`s2conv.utils.rotation`
     - Wigner d- and D-functions and rotations
   * - :mod:`s2conv.utils.evaluation`
     - Evaluation of band-limited fields at arbitrary points
   * - :mod:`s2conv.utils.indexing`
     - Index conventions for harmonic and Wigner coefficients
   * - :mod:`s2conv.utils.equivariance`
     - Equivariance errors over random signals and rotations
